# 🐾 ZQ Pet Store – Children's Web Game

A fun, colorful pet adoption web game for children, built with **.NET 10 ASP.NET Core**.

## Features
- 🏪 **Pet Shop** – browse 8 adorable virtual pets
- ❤️ **Adopt** pets using in-game coins
- 🎮 **Guess the Pet!** mini-game to earn coins
- 🏠 **My Pets** – view your adopted pet collection

## Quick Start

```bash
cd PetStore.Api
dotnet run
```

Then open your browser at **http://localhost:5000**

## Project Structure
```
PetStore.Api/          .NET Web API + static frontend
  Models/              C# model classes
  wwwroot/             Static HTML/CSS/JS game UI
  Program.cs           API endpoints (Minimal API)
docs/superpowers/plans/  Planning documents
```

## Tech Stack
- **Backend:** .NET 10 / ASP.NET Core Minimal API
- **Frontend:** HTML5 + CSS3 + Vanilla JavaScript
- **Data:** In-memory (no database needed)
